
SkillUp Campus.

Es una plataforma educativa colaborativa desarrollada en 8 semanas. 
 
Este repositorio contiene tanto el backend simulado como el frontend SPA.

---------------------------------------------------------------------------------------------------------------------------------------------

Decisiones técnicas.

Frontend: React + Vite + TailwindCSS + DaisyUI.
Backend: Node.js + Express (con mocks en JSON).
Base de datos: MongoDB Atlas (previsto) / JSON Server (para pruebas locales).
Gestión de proyecto: Trello (Kanban).

---------------------------------------------------------------------------------------------------------------------------------------------

Comandos de inicio.

Backend.

cd backend
npm install
npm start

Frontend.

cd frontend
npm install
npm run dev
